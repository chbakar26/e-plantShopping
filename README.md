# Paradise Nursery Shopping Application

A React-based front-end e-commerce application designed for browsing and purchasing a variety of houseplants. 

## Project Features
* **Landing Page:** Features a welcoming background image, company name, introduction, and a "Get Started" button.
* **Product Listing:** Displays at least six unique houseplants categorized into three distinct groups. Includes an "Add to Cart" functionality that dynamically updates the global state.
* **Shopping Cart:** An interactive cart page displaying added items, individual unit prices, sub-totals, and the grand total. Users can increment, decrement, or delete items before proceeding to checkout.
* **State Management:** Utilizes Redux Toolkit for efficient global state handling of the shopping cart.
